# Fig. 1. Offline error against model size

| File | Content |
|---|---|
| `fig_teaser_paper.pdf` | the figure as it appears in the paper |
| `data/fig1_points.csv` | the seven plotted points: parameter count and macro MSE on the 870 validation calls, with the source of each |

The figure was drawn by a co-author from these values; the package has no script for its exact styling. Every value
is checked elsewhere in the package: the macro MSE column is Table I (`table1_offline_accuracy/`, regenerated by
`scripts/paper/make_tables_v2.py`), and the parameter counts of the three ONNX baselines are the sizes of their
initializers, for example

```bash
python3 -c "import onnx, numpy as np; m = onnx.load('experiments/results/switch_deploy_v1/models/pioneer.onnx'); print(sum(int(np.prod(t.dims)) for t in m.graph.initializer))"
```

which prints 485679. The deployed estimator's 683 160 parameters are counted as in
[the results index](../../docs/RESULTS_INDEX.md); the Decision Transformer point is drawn off scale at the top of the
figure, at its macro MSE of 10.828.
